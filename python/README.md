# Лабораторная работа 1. Классификация изображений: от kNN до полносвязных сетей

В этой работе вы шаг за шагом построите конвейер классификации изображений на датасете
[CIFAR-10](https://www.cs.toronto.edu/~kriz/cifar.html) (60 000 цветных картинок 32×32,
10 классов) и реализуете с нуля на NumPy:

* классификатор методом k ближайших соседей и кросс-валидацию;
* линейный softmax-классификатор, его функцию потерь и градиент, обучение SGD;
* модульные слои нейронной сети (прямой и обратный проход) и двухслойную сеть;
* классификацию по признакам изображений (HOG и цветовая гистограмма);
* многослойную полносвязную сеть и правила обновления SGD+momentum, RMSProp и Adam.

Весь код работает на NumPy — GPU не требуется. Датасет (~170 МБ) скачивается сам при
первом запуске ноутбука, см. «Датасет» ниже.

## Порядок выполнения

## Как работать

1. На странице задания на платформе нажмите «Начать задание» — у вас появится свой форк.
   Склонируйте его по SSH (ключ выдаётся там же, в «Доступ по SSH») и перейдите в папку
   `python/`:

   ```bash
   git clone <адрес вашего форка>
   cd <папка форка>/python
   ```

2. Поставьте окружение через [uv](https://docs.astral.sh/uv/) — те же версии библиотек, на
   которых платформа проверяет решение:

   ```bash
   uv sync                 # создаст .venv с numpy, scipy, matplotlib, pytest и Jupyter
   uv run jupyter lab      # откройте ноутбуки
   ```

3. Выполняйте ноутбуки по порядку. Первой запускайте ячейку «Настройка окружения».
4. Проверяйте код тестами — это те же тесты, которыми платформа выставляет автобалл:

   ```bash
   uv run pytest                          # все тесты
   uv run pytest tests/test_knn.py        # тесты одного ноутбука
   ```

   Менять тесты бесполезно: при проверке платформа берёт свою копию папки `tests/`.
5. Сдача — `git commit` и `git push` изменений в папке `python/`, затем «Сдать решение» на
   странице задания. «Запустить CI без сдачи» прогонит тесты, не отправляя работу.

**Colab.** Если вам удобнее Google Colab, загрузите туда папку `python/` сами и откройте
ноутбук из неё: ячейка настройки проверит, что рядом лежит пакет `dlcv`, и скачает датасет.
Результаты (`.py` и ноутбуки с выводами) потом всё равно нужно закоммитить в форк.

## Датасет

Функция `ensure_cifar10()` (её вызывает ячейка настройки) скачивает архив CIFAR-10 в
`dlcv/datasets/`, проверяет контрольную сумму и распаковывает. Сначала — с сервера курса,
а если он недоступен — с [официального сайта](https://www.cs.toronto.edu/~kriz/cifar.html).
Источник можно задать явно:

```bash
DLCV_DATASET_SOURCE=official uv run jupyter lab   # или racoon
```

Папка `dlcv/datasets/` в git не попадает (см. `.gitignore`).

## Что входит в выполненную работу

* все пять ноутбуков — с выполненными ячейками (выводы и графики должны быть сохранены) и
  ответами на вопросы;
* изменённые файлы пакета: `dlcv/classifiers/k_nearest_neighbor.py`,
  `dlcv/classifiers/softmax.py`, `dlcv/classifiers/linear_classifier.py`,
  `dlcv/classifiers/fc_net.py`, `dlcv/layers.py`, `dlcv/optim.py`.

Автобалл — доля пройденных тестов (`tests/`). Итоговую оценку ставит преподаватель: он
смотрит код, выводы ноутбуков и ответы на вопросы. Датасет и сохранённые модели
(`dlcv/saved/*.npy`) прикладывать не нужно — платформа принимает только текстовые файлы.

## Структура папки

```
python/
├── knn.ipynb, softmax.ipynb, two_layer_net.ipynb, features.ipynb, FullyConnectedNets.ipynb
├── pyproject.toml, uv.lock     — окружение (uv)
├── tests/                      — тесты (те же, что на платформе)
└── dlcv/                       — пакет с кодом лабораторной
    ├── classifiers/            — классификаторы (kNN, softmax, полносвязные сети)
    ├── layers.py, layer_utils.py — слои нейронной сети
    ├── optim.py                — правила обновления параметров
    ├── solver.py               — цикл обучения (класс Solver)
    ├── features.py             — извлечение признаков изображений
    ├── gradient_check.py       — численная проверка градиентов
    ├── data_utils.py, vis_utils.py — загрузка данных и визуализация
    ├── datasets/               — сюда скачивается CIFAR-10 (в git не хранится)
    └── saved/                  — сюда сохраняются обученные модели
```
